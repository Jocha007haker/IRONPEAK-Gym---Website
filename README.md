# IRONPEAK Gym — Website

Sitio web desarrollado para un gimnasio ficticio de alto rendimiento, creado **desde cero como parte de mi portafolio de desarrollo web**.

## 📌 Sobre el proyecto

IRONPEAK Gym es una página web diseñada para representar la presencia digital de un gimnasio moderno enfocado en entrenamiento, rendimiento físico y acondicionamiento.

El proyecto fue creado desde cero con un enfoque visual deportivo, buscando transmitir una identidad fuerte, moderna y profesional.

## 🛠️ Tecnologías utilizadas

* HTML5
* CSS3

## ✨ Características

* Diseño moderno orientado al sector fitness
* Interfaz visual enfocada en rendimiento deportivo
* Estructura web organizada
* Secciones informativas para el gimnasio
* Diseño adaptable a diferentes tamaños de pantalla
* Desarrollo realizado desde cero
